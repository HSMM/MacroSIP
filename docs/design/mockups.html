Intent

The fastest path from "I know the number" to a ringing call. The number field is focused whenever the window is key, so typing digits works without clicking.

Interaction

  • Keys on screen and the keyboard both type into the field; ⌫ deletes, ↩ calls, long-press 0 gives +.
  • The account picker sets the outgoing account for this call only; its default comes from "Default for outgoing". The dot shows that account's registration.
  • Pasting sip: or tel: URIs and numbers with spaces or dashes is accepted; the dial string is normalised on call.
  • Status bar: one item per enabled account. A failed account shows the short reason in red; clicking an item opens that account in Settings.

Open questions

  1. Q1.1Should typing letters jump to the Contacts tab with search results, or show inline suggestions under the field and stay on Dialpad?
  2. Q1.2Do you want a redial shortcut (empty field + Call redials the last number, like MicroSIP)?

Intent

Everything you need during a call stays in the same window as the dialpad and contacts, so you can look up a transfer target without switching windows.

Interaction

  • Mute, Hold and Record are toggles: filled when on. Transfer opens a popover with contact suggestions and two actions: Transfer Now (blind) and Call First (attended, leads to screen 5).

Intent

Handle a second call without losing the first. Exactly one call is active; every other call is held, and the row list makes that visible at a glance.

Interaction

  • Clicking a held row (or its Resume button) makes it active and holds the current one. The button row and End Call act on the active call; each row also has its own small red end button.
  • A new incoming call while on a call shows the incoming window (screen 6); Answer holds the current call.
  • Attended transfer: Transfer → Call First puts the original call on hold and calls the target. The banner completes or cancels the transfer.
  • Window title shows the active party when the window is in the background.
Full: Merge joins all connected calls into a local conference (mixed on this Mac). Split takes one participant back out as a held call. Ending the conference ends every leg.

Intent

An incoming call must be impossible to miss and quick to act on, wherever you are working, without stealing keyboard focus from the app you are typing in.

Interaction

  • Non-activating floating panel on all Spaces, centred on the screen with the pointer; it can be dragged and remembers its position.
  • Shortcuts while it is visible: ⌘↩ answer, ⌘. decline. Esc only silences the ringtone.
  • The notification carries Answer / Decline actions, so the call can also be handled from Notification Center or a locked screen. Both disappear when the call is answered, declined or cancelled by the caller.
  • Decline sends 486 Busy Here. An unanswered call becomes a missed call (badge on Dock, menu bar, Call Log tab).
Full: countdown ring "Auto-answer in N s" with Cancel when auto-answer applies (mode All, or Contacts only and the caller is a contact). A server answer-after header shows the same strip.

Open questions

  1. Q6.1Should the floating window appear when the main window is already frontmost, or should the call then show only inside the main window?
  2. Q6.2Notification style: banner (disappears) or alert (stays until acted on)? macOS lets the user change it, but we pick the default request.

Intent

MacroSIP keeps running in the menu bar when its window is closed. The menu answers "am I reachable?" and lets you place or return a call without opening the main window.

Interaction

  • Account lines are informational; clicking one opens it in Settings › Accounts. A failed line shows the SIP reason.

Intent

One sheet holds everything about an account. Required fields are only server, username and password; everything else has a sensible default.

Interaction

  • Save validates the fields, stores the password in the Keychain and re-registers. The status beside the buttons updates live.
  • "Account name" is the short label used in the picker, status bar and call panel ("Office"). Not in the brief, but those places need something shorter than the full address.
  • Only one account can be default; turning it on here turns it off on the previous default.
  • Delete asks for confirmation and removes the Keychain item too.
Full: "Publish my presence" per account. Contacts' presence subscriptions go through the account they are reached on.

Intent

On first launch there is exactly one useful thing to do. The window says so and offers one button, without a multi-step wizard.

Interaction

  • "Add Account…" opens the account editor (screen 9) as a sheet on this window. After Save the empty state disappears and the dialpad is live.
