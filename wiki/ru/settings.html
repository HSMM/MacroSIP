Настройки

Настройки открываются сочетанием ⌘, из меню MacroSIP, меню выбора аккаунта или значка в строке меню. Это стандартное окно настроек macOS с вкладками на панели инструментов; изменения применяются сразу, кнопки «Сохранить» нет. Вкладки по порядку: Основные, Аккаунты, Звук, Сеть, Кодеки, Запись, Звонки, Быстрые клавиши, Справочник.

Основные

Строка Значение
Запускать при входе в систему Регистрирует MacroSIP как объект входа.
Оставаться в строке меню после закрытия окна Если выключить, закрытие окна завершает приложение.
Показывать значок в Dock Скрывает или показывает значок в Dock; значок в строке меню остаётся.
Не беспокоить Выкл. / Вкл. / На 30 минут / На 1 час / До завтра 9:00. «Отклоняет входящие звонки с кодом 486 Busy Here и публикует статус „Не беспокоить“.» Пока идёт отсчёт, показывает «До 14:30 · осталось 27 мин».
Язык Системный / English / Русский. «Изменение вступит в силу после перезапуска MacroSIP.»
Обновления Проверять обновления автоматически (раз в день, спрашивает перед установкой), Включать предварительные версии, Проверить, «Последняя проверка: …». См. Установка.
Дополнительно › Ссылки «Открывать ссылки sip: и tel: в MacroSIP» с кнопкой Назначить (предупреждение называет другое приложение, которое обрабатывает ссылки tel:). При открытии ссылки: Спрашивать (подставляет номер в поле) / Звонить сразу / Только подставить.
Дополнительно › Устранение неполадок Файл журнала с кнопкой Открыть папку (~/Library/Logs/MacroSIP/MacroSIP.log, по 2 МБ на файл, 3 файла) и Диагностика с кнопкой Скопировать (версии, аккаунты и настройки, без паролей).

Группа «Дополнительно» по умолчанию свёрнута.

Аккаунты

Таблица с точкой состояния, колонками Имя (синий бейдж Основной у основного аккаунта для исходящих), Адрес, Транспорт и Статус (Подключён, Регистрация…, короткая ошибка вроде 403, Выключен, Только исходящие, Переподключение…). Перетаскивание меняет порядок; он используется в меню выбора аккаунта и строке состояния. Кнопки +, − (с подтверждением) и Изменить…; двойной щелчок открывает редактор. При восьми и более аккаунтах появляется поле Фильтр аккаунтов. Группа «Офис · последняя ошибка» показывает последний сбой REGISTER с кнопкой Повторить. Поля редактора описаны на странице Аккаунты; в его группе «Дополнительно» есть строки голосовой почты Номер голосовой почты («Набирается из строки меню и строки состояния.») и Индикатор голосовой почты (MWI) («Показывает число новых сообщений, о которых сообщает сервер.»).

Звук

Группа Строки
Устройства Микрофон (индикатор уровня, список с вариантом «Как в системе»), Динамик (список), Устройство для звонка, Переключаться на гарнитуру при подключении, Кнопки гарнитуры («Подключено: Jabra Evolve2 65» или «Гарнитура с кнопками управления не подключена»).
Мелодия звонка Мелодия (Классическая / Цифровая / Мягкая / Свой файл…, с кнопкой Прослушать), Громкость 0–100 %.
Музыка на удержании Источник: Встроенная / Свой файл… / Выкл. «Это слышит собеседник, пока звонок на удержании.»
Звуковые события Соединение и завершение звонка, Нажатия клавиш номеронабирателя, Новое голосовое сообщение, Ошибка регистрации и потеря сети; все выключены. «Короткие сигналы в динамике; собеседник их не слышит.»
Проверка звука Динамик и микрофон: кнопка Проверить и индикатор микрофона. «Проверка 2 секунды играет две ноты в динамике; индикатор показывает уровень микрофона.»
Обработка Эхоподавление: «Выключайте, только если у гарнитуры есть собственное эхоподавление.»

Подробности на странице Звук.

Сеть

Группа Строки По умолчанию
Подключение STUN-сервер («Оставьте пустым, если вы не за NAT.»), Локальный порт SIP («0 — выбрать свободный порт автоматически.»), Интервал keep-alive в секундах («Не даёт закрыться NAT-соединению между регистрациями.»), Использовать ICE («Находит рабочий путь для медиа через NAT. Использует STUN-сервер выше.»). пусто, 5060, 15, вкл.
RTP Диапазон портов с полями Начало и Портов («Звук использует этот диапазон. На один звонок нужно два порта; 1024–65535.»), Использовать rport («Просит сервер отвечать на адрес и порт, с которых пришёл запрос. Помогает за NAT.»). 4000 / 1000, вкл.
DNS Использовать SRV-записи DNS («Находит сервер и порт учётной записи по SRV-записям, а если их нет, обращается к самому домену.»), DNS-сервер («Адрес DNS-сервера. Если пусто, берутся системные.»), доступен только при включённых SRV. выкл., пусто

«При смене порта все аккаунты регистрируются заново. Текущие звонки не прерываются. Транспорт и SRTP задаются для каждого аккаунта в его настройках.» Диапазон портов и DNS применяются после перезапуска движка; оранжевый баннер предлагает Перезапустить сейчас (недоступно во время звонка: «Сначала завершите звонки.»). Допустимые значения: локальный порт 0 или 1024–65535, keep-alive 0 (выкл.) или 5–600 с.

Кодеки

«Аудиокодеки в порядке предпочтения»: таблица с флажком, колонками Кодек, Частота, Битрейт и ручкой перетаскивания; кнопки Выше, Ниже, Сбросить. Кодеки без флажка никогда не предлагаются; хотя бы один должен остаться включённым. Группа Opus добавляет Коррекция потерь пакетов (FEC) (вкл.) и Подавление тишины (DTX) (выкл.). Список кодеков — на странице Звук.

Запись

Строка Значение
Сохранять записи в Список папок, по умолчанию «MacroSIP Recordings» в ~/Music; Выбрать папку…. «Папка не найдена», если она пропала.
Записывать все звонки автоматически По умолчанию выключено; кнопка «Запись» на панели звонка работает в любом случае.
Каналы Моно («Обе стороны смешаны в один канал.») или Стерео («Вы в левом канале, собеседник в правом.»).
Тон уведомления › Воспроизводить тон во время записи По умолчанию выключено. Короткий сигнал, который слышат обе стороны и который попадает в запись: через секунду после начала записи и затем Каждые 5–60 секунд (15). «Короткий сигнал каждые 15 секунд сообщает обеим сторонам, что звонок записывается.»
Показать папку с записями Показать в Finder.

Подпись: «Записи сохраняются в M4A (AAC). Временные WAV-файлы удаляются после преобразования.» и «Имя файла: 2026-10-10 14.52 Алеся Козловская (in).m4a».

Звонки

Группа Строки
Входящие звонки Отклонять звонки от: Никого / Всех / Номеров не из контактов / Анонимных абонентов. «Отклонённый звонок не звонит. Абонент получает 603 Decline, а в журнале звонков появляется „Отклонён: правило“.»
Во время звонка Когда звонят во время разговора: Ожидание вызова (сигнал, окно) / Только окно / Занято (один звонок). Способ передачи DTMF: Автоматически / RFC 2833 / SIP INFO / В звуке (in-band) («Автоматически: RFC 2833, при отказе SIP INFO.»). Выводить главное окно вперёд при входящем звонке («Окно входящего звонка тоже появляется.»).
Автоответ Отвечать на входящие автоматически: Выкл. / Все звонки / Контакты. Задержка перед ответом в секундах (5). Учитывать запрос сервера на ответ («Отвечает, когда АТС присылает Call-Info: answer-after=N (интерком, оповещение), даже если режим выключен.»).

Подпись: «„Не беспокоить“ важнее автоответа. Автоответ никогда не принимает второй звонок, пока вы уже разговариваете.» См. Входящие-звонки.

Быстрые клавиши

Таблица из 12 строк (Имя, Номер, Тип, BLF, Клавиша), счётчик «5 из 12 клавиш», затем Панель › Показывать панель (Выкл. / Справа / Снизу) и Код перехвата (*8). См. Быстрые-клавиши.

Справочник

Контакты › Сортировка (По имени / По фамилии); список источников с колонками Источник, Состояние, Вкл., кнопками +, −, Изменить… и Импортировать; группа Поиск с настройками Искать в справочниках из поля номера, Минимум символов (2), Результатов от источника (5) и Искать имена входящих абонентов. См. Справочник.

Где хранятся настройки

~/Library/Application Support/MacroSIP/settings.json (а также accounts.json, contacts.json, calllog.json); пароли — в связке ключей входа. См. Решение-проблем.
