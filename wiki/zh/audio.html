设置

通过 ⌘, 从 MacroSIP 菜单、账户弹出菜单或菜单栏图标打开设置 (Settings)。它是一个标准的 macOS 设置窗口，带有工具栏标签页；更改立即生效，没有“存储”按钮。标签页按顺序为：通用 (General)、账户 (Accounts)、音频 (Audio)、网络 (Network)、编解码器 (Codecs)、录音 (Recording)、通话 (Calls)、快捷键 (Quick keys)、目录 (Directory)。

通用

行 含义
登录时启动 (Launch at login) 将 MacroSIP 注册为登录项。
关闭窗口后继续在菜单栏中运行 (Keep running in the menu bar when the window is closed) 关闭：关闭窗口即退出应用。
在 Dock 中显示图标 (Show icon in the Dock) 隐藏或显示 Dock 图标；菜单栏图标保留。
勿扰模式 (Do Not Disturb) 关闭 / 开启 / 30 分钟 / 1 小时 / 直到明天 9:00。“拒接来电，并向关注您的联系人显示勿扰状态。”计时运行时显示“直到 14:30 · 剩余 27 分钟”。
消息 › 文字消息 (SIP MESSAGE) (Messages › Text messages (SIP MESSAGE)) 开关，默认关闭。“显示“消息”标签页，接收来信，并在“联系人”和“通话记录”菜单中添加“发送消息”。”关闭时没有“消息”标签页、没有“发送消息”菜单项、没有通知和提示音，收到的消息会被丢弃。见 消息。
语言 (Language) 系统 / English / Русский。“在 MacroSIP 重新启动后生效。”
更新 (Updates) 自动检查更新 (Check for updates automatically)（“启动时以及每天一次。MacroSIP 在安装更新前会先询问。”）、包含候选发布版 (Include release candidates)、立即检查 (Check Now)、“上次检查于…”或“尚未检查”。见 安装。
高级 › 链接 (Advanced › Links) “用 MacroSIP 打开 sip: 和 tel: 链接”，附设为默认 (Make Default)（警告会指出另一个处理 tel: 链接的应用）。打开链接时 (When a link is opened)：呼叫前询问（填入号码栏）/ 立即呼叫 / 仅填入拨号栏（“选“仅填入拨号栏”可让您先核对号码。”）。
高级 › 故障排除 (Advanced › Troubleshooting) 打开日志文件夹 (Open Log Folder)（“保存在 ~/Library/Logs/MacroSIP。三个文件，每个 2 MB（调试模式下 8 MB）。”）和拷贝诊断信息 (Copy Diagnostics)（“版本、账户和设置，不含密码。可粘贴到问题报告中。”）。
Debug mode 开关，默认关闭。“向日志添加 SIP 消息和更多细节，因此增长更快。用完后请关闭。”日志文件每个增长到 8 MB。开启后会跨启动保持，直到关闭为止；如果启动时使用了 --log-level，以该级别为准，此开关将被禁用。见 故障排除。
Create Archive… “一个 ZIP，包含日志文件、诊断报告和最近的崩溃报告。其中有电话号码和服务器地址，但没有密码。请只发给您信任的人。”见 故障排除。

“高级”组默认折叠。

账户

一个表格，包含状态圆点、名称 (Name)（默认外拨账户上有蓝色的默认 (Default) 标记）、地址 (Address)、传输 (Transport) 和状态 (Status)（已注册、正在注册…、简短错误如 403、已停用、需要密码 (Needs password)、仅外拨、正在重新连接…）。拖移可重新排序；此顺序用于账户弹出菜单和状态栏。按钮 +、−（需确认）和编辑… (Edit…)；连按可编辑。页脚右侧的 Import from MicroSIP… 导入 MicroSIP 的账户和联系人（见 账户）。账户达到八个或更多时出现过滤账户 (Filter accounts) 字段。“Office · 上次错误”组显示上次 REGISTER 失败并提供重试 (Retry)。编辑器的字段在 账户 中介绍；其“高级”组包含语音信箱行语音信箱号码 (Voicemail number)（“从菜单栏和状态栏拨打。”）和语音信箱指示 (MWI) (Voicemail indicator (MWI))（“显示服务器报告的新留言数量。”）。

音频

组 行
设备 (Devices) 麦克风 (Microphone)（电平表，含“系统默认”的弹出式菜单）、扬声器 (Speaker)（弹出式菜单）、铃声设备 (Ringtone device)（“即使通话使用耳机，也通过扬声器播放铃声。”）、连接耳机时自动切换 (Switch to a headset when it is connected)、耳机按键 (Headset buttons)（“已连接：Jabra Evolve2 65”或“没有带通话控制键的耳机”）。
铃声 (Ringtone) 声音 (Sound)（经典 / 数字 / 柔和 / 自定文件…，附播放 (Play)；预听播放真正的选择，音量为所设音量；无法读取的文件保留之前的选择并显示“无法使用铃声文件：…”）、音量 (Volume) 0–100 %。“自定文件…”接受 WAV、AIFF、M4A 和 MP3。详见 音频。
保持音乐 (Hold music) 来源 (Source)：内置 / 自定文件… / 关闭。“对方在通话保持期间会听到此内容。”
声音事件 (Sound events) 通话接通与结束 (Call connected and ended)、拨号键盘按键 (Dial pad key presses)、新语音留言 (New voicemail)、注册错误与网络断开 (Registration error and lost network)，消息开启时还有新消息 (New message)；全部关闭。“扬声器上的短促蜂鸣声；对方听不到。”
音频测试 (Audio test) 扬声器与麦克风 (Speaker and microphone)：测试 (Test) 和麦克风电平表。“在扬声器上播放两个音 2 秒；电平表显示麦克风电平。”
处理 (Processing) 回声消除 (Echo cancellation)：“仅当您的耳机自身消除回声时才关闭。”

详见 音频。

网络

组 行 默认
连接 (Connection) STUN 服务器 (STUN server)（“如果您不在 NAT 后，请留空。”）、本地 SIP 端口 (Local SIP port)（“0 表示自动选取一个空闲端口。”）、以秒为单位的保活间隔 (Keep-alive interval)（“在两次注册之间保持 NAT 绑定开放。”）、使用 ICE (Use ICE)（“帮助音频穿过 NAT。使用上方的 STUN 服务器。”）。 空、5060、15、开
RTP 带起始 (Start) 和端口数 (Ports) 的端口范围 (Port range)（“通话音频的端口，1024–65535。每路通话需要两个。”）、使用 rport (Use rport)（“在 NAT 后有帮助：服务器回复到您发起呼叫的地址。”）。 4000 / 1000、开
DNS 使用 DNS SRV 记录 (Use DNS SRV records)（“自动查找账户的服务器；失败时使用域本身。”）、域名服务器 (Nameserver)（“DNS 服务器地址。留空则使用系统的服务器。”），仅在 SRV 开启时可用。 关、空

“更改端口会重新注册所有账户；进行中的通话不会中断。传输和 SRTP 按账户设置。”页脚“端口范围和 DNS 的更改在重新启动后生效。”针对端口范围和 DNS；横幅“网络更改将在重新启动后生效。账户将重新注册。”提供立即重新启动 (Restart now)（通话期间禁用：“请先结束通话。”）。

服务器使用私有地址（10.x、172.16–31.x、192.168.x 或 100.64–127.x，在局域网内或通过 VPN）的账户，无论上面填了什么，都不使用 STUN 服务器：Mac 报出自己的地址，服务器不必再去更正。见 账户。有效值：本地端口 0 或 1024–65535，保活 0（关闭）或 5–600 秒。

编解码器

“音频编解码器，按优先顺序”：一个表格，包含复选框、编解码器 (Codec)、采样率 (Sample rate)、比特率 (Bitrate) 和拖移手柄；上移 (Move up)、下移 (Move down)、恢复默认 (Restore Defaults)。未勾选的编解码器绝不会被提供；至少要保留一个启用（“拖移行或使用箭头重新排序。未勾选的编解码器绝不会被提供。至少要保留一个编解码器启用。”）。Opus 组增加丢包修复 (FEC) (Packet-loss correction (FEC))（开）和静音抑制 (DTX) (Silence suppression (DTX))（关）。编解码器列表在 音频 中。

录音

行 含义
录音保存位置 (Save recordings to) 文件夹弹出式菜单，默认为 ~/Music 中的“MacroSIP Recordings”；选取文件夹… (Choose Folder…)。文件夹丢失时显示“未找到文件夹”。
自动录制所有通话 (Record all calls automatically) 默认关闭；无论如何通话面板中的“录音”按钮都可用。
声道 (Channels) 单声道 (Mono)（“双方混合到一个声道。”）或立体声 (Stereo)（“您在左声道，对方在右声道。”；自 26.2 起两个声道保持同步，见 通话）。
提示音 › 录音时播放提示音 (Notice tone › Play a notice tone while recording) 默认关闭。双方都能听到并写入录音的短促蜂鸣声，录音开始一秒后播放，之后每 (Every) 5–60 秒 (seconds)（15）播放一次。“每 15 秒一次的短促蜂鸣声提醒双方通话正在被录音。”
显示录音文件夹 (Show Recordings Folder) 在访达中打开 (Open in Finder)。

页脚：“录音保存为 M4A 文件；临时 WAV 之后会被删除。”以及“文件名：2026-10-10 14.52 姓名或号码 (in).m4a”。

通话

组 行
来电 (Incoming calls) 拒接来自以下来电者的来电 (Reject calls from)：无 / 所有人 / 不在联系人中的号码 / 匿名来电者。“被拒接的来电绝不会响铃。来电者会收到拒绝，通话记录显示‘已拒接：规则’。”
通话期间 (During a call) 通话期间有来电时 (When a call comes in during a call)：呼叫等待（提示音和窗口）/ 仅窗口 / 忙线（单通话模式）。DTMF 方式 (DTMF method)：自动 / RFC 2833 / SIP INFO / 带内（“自动会选取您的服务器支持的方式。”）。来电时将主窗口置于最前 (Bring the main window to the front on an incoming call)（“无论如何来电窗口都会出现。”）。
全局热键 (Global hotkeys) Use hotkeys in any app（默认关闭），之后是 Answer、Hang up 和 Mute 的按键框。建议组合为 ⌃⌥A、⌃⌥H 和 ⌃⌥M。见 通话。
自动接听 (Auto-answer) 自动接听来电 (Answer incoming calls automatically)：关闭 / 所有来电 / 仅联系人。以秒为单位的接听前延迟 (Delay before answering)（5）。遵从服务器的 answer-after 请求 (Honour the server's answer-after request)（“当 PBX 要求时接听（对讲、广播），即使自动接听已关闭。”）。

页脚：“勿扰模式优先于自动接听。您已在通话时，自动接听绝不会接听第二路来电。”见 来电。

快捷键

一个 12 行的表格（名称 (Name)、号码 (Number)、类型 (Type)、BLF、按键 (Key)），“12 个键中的 5 个”，然后是面板 › 显示面板 (Panel › Show panel)（关闭 / 右侧 / 底部）和代接代码 (Pickup code)（*8）。见 快捷键。

目录

联系人 › 排序方式 (Contacts › Sort by)（名字 / 姓氏）；来源列表包含来源 (Source)、状态 (Status)、开 (On)，按钮 +、−、编辑… (Edit…) 和立即导入 (Import now)；搜索 (Search) 组包含从号码栏搜索目录 (Search directories from the number field)、最少字符数 (Minimum characters)（2）、每个来源的结果数 (Results per source)（5）和查询来电者姓名 (Look up names of incoming callers)。见 目录。

设置的存储位置

~/Library/Application Support/MacroSIP/settings.json（以及 accounts.json、contacts.json、calllog.json）；密码在登录钥匙串中。见 故障排除。
