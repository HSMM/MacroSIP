账户

一个账户 (Account) 就是一个 SIP 身份：用户、服务器、凭据和传输方式。多个账户可以同时启用并注册；其中一个是默认外拨账户 (default outgoing account)。

添加账户

可以从首次启动界面（添加账户… (Add Account…)）、设置 › 账户（+、编辑… (Edit…) 或连按某一行）或账户弹出菜单（账户设置… (Account Settings…)，⌘,）打开编辑器。

通常只需填写基本字段：

字段 含义
账户名称 (Account name) 在账户弹出菜单、状态栏、通话面板和菜单栏中使用的简短标签，例如“Office”。
SIP 服务器 (SIP server) 主机名或 IP 地址，例如 pbx.example.com。值无效时显示“请输入类似 pbx.example.com 的主机名，或一个 IP 地址。”
用户名 (Username) SIP 用户，例如 andrei。
密码 (Password) 仅存储在登录钥匙串中，绝不写入文件。
启用 (Enabled) 关闭后停止注册和外拨；账户仍以灰显状态留在弹出菜单中，但从状态栏消失。设置和钥匙串项会保留。

存储 (Save) 将密码存入钥匙串并开始注册；按钮旁的状态实时更新（“未存储”、“正在注册…”、“已注册”）。

“高级”组

其他所有内容都折叠在高级 (Advanced) 展开组中。只要其中任何一个值与默认值不同，该组就会自动展开，这样您就能看出账户为何表现如此。

行 含义 默认值
显示名称 (Display name) “显示给您呼叫的对方。”发送给远端的来电显示名。 空
认证用户名 (Auth username) “仅在与用户名不同时填写。”用于摘要认证。 空
域 (Domain) “留空则使用 SIP 服务器。”用于从拨号字符串构建 SIP URI。 空
出站代理 (Outgoing proxy) 路由集，例如 sip:proxy.example.com;lr。 空
传输 (Transport) UDP、TCP 或 TLS。 UDP
媒体加密 (SRTP) (Media encryption (SRTP)) 禁用、可选或强制。SRTP 与信令传输方式相互独立。 禁用
注册有效期 (Registration expiry) 60 到 3600 秒。 300
验证服务器证书 (Verify server certificate) 仅 TLS。“仅对使用自签名证书的服务器关闭。” 开
语音信箱号码 (Voicemail number) “从菜单栏和状态栏拨打。”语音信箱项所呼叫的号码或 SIP URI，例如 *97。位于“语音信箱”组中。 空
语音信箱指示 (MWI) (Voicemail indicator (MWI)) “显示服务器报告的新留言数量。”订阅服务器的 message-summary；新留言在状态栏显示为信封标记，在菜单栏显示为“语音信箱”项（见 来电）。服务器未经订阅直接推送的指示也会显示。 开
向服务器注册 (Register with server) 关闭后该账户仅用于外拨：从不注册，不接收来电，并在设置 › 账户中显示“仅外拨”。 开
默认用于外拨 (Default for outgoing calls) 只能有一个默认账户；开启此项会清除之前的默认账户。 第一个账户为开
发布我的在线状态 (Publish my presence) “让关注您的联系人看到在线 / 离开 / 勿扰。” 关

STUN、ICE、本地 SIP 端口和保活不是按账户设置的；它们位于设置 › 网络（见 设置）。

**私有服务器不使用 STUN。**服务器使用私有 IP 地址（10.x、172.16–31.x、192.168.x 或 100.64–127.x，例如局域网内或通过 VPN 访问的办公室 PBX）的账户，不使用设置 › 网络中的 STUN 服务器。首次注册改为携带 Mac 自己的地址，而不是 STUN 会找到的公网地址，因为网络内部的服务器无法通过那个公网地址访问。服务器不必再更正地址，来电也能从不改写该地址的服务器送达。无需任何设置：自 26.2 起自动生效。

“测试”按钮

填写 SIP 服务器、用户名和密码后，测试 (Test) 按钮即可用。它用一个临时账户注册，并在原位显示结果：

结果 文本
成功 “注册成功 (120 ms)”
被拒绝 “测试失败：401 Unauthorized”（或 403 等），附带“服务器拒绝了用户名或密码。未存储任何内容。”和重新测试 (Test Again) 按钮。
无应答 “测试失败：无响应”，附带“服务器未及时应答。未存储任何内容。”

多个账户

设置 › 账户列出所有账户，包括状态圆点、名称（蓝色的默认 (Default) 标记表示默认外拨账户）、地址、传输和状态。拖移行可重新排序；此顺序用于账户弹出菜单和状态栏。账户达到八个或更多时会出现过滤账户 (Filter accounts) 字段来缩小列表。

− 在确认“删除账户‘Office’？”——“其密码将从钥匙串中移除。通话记录会保留。”后移除所选账户。

从 MicroSIP 导入

在 Settings › Accounts 中点击 Import from MicroSIP…，即可导入 MicroSIP 安装中的账户和联系人。MacroSIP 不读取 MicroSIP 的其他任何内容。

  1. 找到 MicroSIP.ini。 在 Windows 上，MicroSIP 通常将它放在 MicroSIP.exe 旁边，或放在 %APPDATA%\MicroSIP 中。将该文件复制到您的 Mac，并在文件选择器中选中它。
  2. 检查预览。 同一文件夹中的 Contacts.xml 会被自动使用；Contacts file 一行可以选择其他文件，或选择 Don't import contacts。预览列出待导入的账户、联系人数量、Skipped（MacroSIP 中已存在，或在文件中重复列出）以及 Warnings。点按 Import 之前不会写入任何内容。
  3. 输入密码。 账户以停用状态导入。MicroSIP 以 MacroSIP 无法读取的形式保存密码，因此请为每个账户输入一次密码以启用它。Enter Password… 会在编辑器中打开第一个导入的账户。其余账户在保存密码之前，会在 Settings › Accounts 列表中显示 Needs password。

文件中没有服务器的账户不会注册，因此不需要密码：它以“仅外拨”账户导入，无需密码即可启用。既没有服务器也没有域的账户会被跳过并给出警告。

对于脚本和管理员，同样的导入也可以在命令行中执行：

/Applications/MacroSIP.app/Contents/MacOS/MacroSIP --import-microsip MicroSIP.ini [--contacts Contacts.xml] [--dry-run]

--dry-run 只打印报告，不写入任何内容。该命令会添加账户（停用、无密码）和联系人。MacroSIP 运行期间它拒绝写入，因此请先退出 MacroSIP。退出码：0 表示导入完成，1 表示被拒绝或失败，2 表示参数错误。

账户弹出菜单

主窗口号码栏上方的按钮显示外拨账户及其注册圆点。点按它打开弹出菜单：

  • 每个账户一行：所选外拨账户带有勾号，然后是圆点、名称以及其下方的 SIP 地址（“andrei@pbx.example.com”；注册失败的账户以红色显示“403 Forbidden · andrei@pbx.example.com”），右侧是一个开关。
  • 点按名称将其选为仅下一次通话的外拨账户并关闭菜单。初始值是默认外拨账户。
  • 开关可在不关闭菜单的情况下启用或停用账户。它与编辑器中的启用和设置 › 账户中的“已停用”是同一个状态。两次点按即可让一个失败的账户安静下来。
  • 账户达到八个或更多时，最上方会出现搜索账户 (Search accounts) 字段，已启用的账户排在已停用的账户之前。
  • 账户设置…（⌘,）打开设置并定位到“账户”。

状态栏与状态

主窗口底部的状态栏按账户顺序为每个已启用账户显示一项。点按某项会打开设置 › 账户并选中该账户。状态栏右端依次是显示新语音留言数量的信封标记（只要有任何账户报告有留言等待就会显示；点按它拨打语音信箱号码，见 来电）、快捷键按钮和一个齿轮按钮，后者打开设置并定位到上次使用的标签页（工具提示“设置…”）。

圆点 状态文本 含义
绿色 账户名称，“已注册” REGISTER 被接受。
橙色 “正在注册…” 已发送 REGISTER，尚无最终应答。持续一两秒属正常。
红色 “Office: 403”；设置 › 账户显示“403 Forbidden — REGISTER 于 14:52 被拒绝。请检查用户名和密码。”并提供重试 (Retry) 服务器拒绝了注册。403 和 401 几乎总是意味着用户名、认证用户名或密码有误。
橙色 “Office · 8 秒后重试”、“Office · 正在重试…”、“正在重新连接…” 临时故障（超时、5xx、连接中断）；引擎按退避策略重试。
灰色空心 灰色账户名称，“仅外拨” 已启用，但向服务器注册已关闭。
灰色空心 “已停用”（仅在设置中显示；账户从状态栏消失） 已关闭。
橙色 Needs password（仅在设置中显示；从 MicroSIP 导入） 在保存密码之前保持停用。
灰色图形 “无网络” Mac 没有可用的网络路径；账户会自行恢复。

已启用账户为一到三个时，每个账户各占一项。从四个起，状态栏只显示一条摘要“6 个中 4 个在线 · 2 个失败”，有账户失败时为红色，仍有账户在连接时为橙色，其余情况为绿色；点按它打开账户弹出菜单。没有任何账户时显示“无账户”，没有账户启用时显示“所有账户已关闭”。
