安装

系统要求

  • macOS 14 (Sonoma) 或更新版本。
  • 搭载 Apple 芯片或 Intel 处理器的 Mac。应用和 DMG 均为通用 (Universal) 版本，同一个下载包在两种架构上都能原生运行。
  • 一个 SIP 账户：电话服务商或 PBX 管理员提供的服务器地址、用户名和密码。联系人和通话记录无需账户即可使用。

Homebrew cask 和 DMG 自 26.0.0 版本起均可使用；从源代码构建的方法见 构建。

使用 Homebrew

brew tap hsmm/tap
brew install --cask hsmm/tap/macrosip

该 cask 安装的是与 GitHub Releases 提供的相同的已签名 DMG。cask 标记为 auto_updates，因此 brew upgrade 不会干预会自行更新的应用。

使用 DMG

  1. 从最新发布版下载 MacroSIP-<version>.dmg。
  2. 打开 DMG，将 MacroSIP 拖移到“应用程序”文件夹。
  3. 按下文所述打开应用一次。

首次启动：Gatekeeper 步骤

MacroSIP 使用临时 (ad hoc) 签名，未经 Apple Developer ID 公证，因此 macOS 第一次会拒绝打开它（“无法打开，因为无法验证开发者”）。以下任一方法执行一次即可：

  • 在“应用程序”中右键点按（或按住 Control 键点按）MacroSIP，选择打开 (Open)，然后在对话框中确认。

  • 或在终端中移除隔离标记：

    xattr -dr com.apple.quarantine /Applications/MacroSIP.app

之后应用即可正常打开。Developer ID 签名和公证计划在获得签名身份后的后续版本中实现。

第一个窗口

没有账户时，主窗口显示“添加一个 SIP 账户以开始通话”和一个添加账户… (Add Account…) 按钮。账户编辑器在 账户 中介绍。菜单栏图标从首次启动起就会出现，处于离线状态。

麦克风权限

MacroSIP 在第一次通话时请求麦克风权限，而不是在启动时。请选择允许 (Allow)。如果拒绝，通话面板会显示“麦克风访问已关闭”并提供打开系统设置 (Open System Settings) 按钮；请在“隐私与安全性”›“麦克风”中允许 MacroSIP。

更新

应用会自行更新。

项目 位置 行为
自动检查 自动 MacroSIP 在启动时检查，之后每天一次，安装前会先询问。
立即检查 MacroSIP 菜单 › 检查更新… (Check for Updates…)，或设置 › 通用 › 更新 › 立即检查 (Check Now) 上次检查日期显示为“上次检查于…”或“尚未检查”。
关闭自动检查 设置 › 通用 › 更新 › 自动检查更新 (Check for updates automatically) “启动时以及每天一次。MacroSIP 在安装更新前会先询问。”
候选发布版 设置 › 通用 › 更新 › 包含候选发布版 (Include release candidates) “下一版本的测试构建，在正式发布前提供。”当前运行的构建本身是候选发布版时默认开启，否则默认关闭。

更新经过签名 (EdDSA) 并在安装前验证，更新后的应用打开时不会出现首次启动对话框。通话期间发现的更新会等到最后一路通话结束；通话中点按“安装并重新启动”同样会等待。有通话进行时退出会询问“结束通话并退出？”。

由于应用使用临时签名，macOS 会将麦克风权限绑定到确切的构建。每次更新后 macOS 都会再次请求麦克风访问权限；在第一次通话时再允许一次即可。应用改用 Developer ID 签名后，这一情况将不再出现。

“更新仅在已安装的应用中有效”：从构建文件夹运行的构建或以模拟引擎启动的构建不会检查更新。

登录时启动

设置 › 通用 › 登录时启动 (Launch at login) 将 MacroSIP 注册为登录项。首次运行时不会就此弹出提示。如果 macOS 需要您批准，该行会显示“请在系统设置 › 通用 › 登录项中允许 MacroSIP。”并提供打开登录项… (Open Login Items…) 按钮。

日志文件的位置

MacroSIP 将日志写入 ~/Library/Logs/MacroSIP/MacroSIP.log，每个文件 2 MB，保留 3 个文件。设置 › 通用中有打开日志文件夹 (Open Log Folder)（在访达中显示日志）和拷贝诊断信息 (Copy Diagnostics)（版本、账户和设置，不含密码，可直接粘贴到问题报告中）。两者都位于“通用”面板底部折叠的高级 (Advanced) 组中，标题为“故障排除”。使用方法见 故障排除。

卸载

将 MacroSIP 拖出“应用程序”（或执行 brew uninstall --cask macrosip）。您的数据保留在 ~/Library/Application Support/MacroSIP/（账户、联系人、通话记录、设置，均为 JSON）和登录钥匙串中（密码，服务名 com.hsmm.macrosip）；录音保留在 ~/Music/MacroSIP Recordings，除非您选择了其他文件夹。若要彻底清除，请手动删除这些内容。
