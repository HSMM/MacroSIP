Messages

MacroSIP can send and receive text messages over SIP (the SIP MESSAGE method). A message is plain text (UTF-8, so Cyrillic and any other language work) and goes through one of your accounts to the SIP server or directly to the other party. SMS that an Asterisk server forwards with chan_dongle arrive as ordinary messages, and your replies go back the same way. The Asterisk and FreePBX setup is described in Asterisk-and-FreePBX-SMS.

Messages are off by default. Until you switch them on there is no Messages tab and no Send Message item, and incoming messages are ignored.

Switching messages on

Open Settings › General (⌘,) and turn on Text messages (SIP MESSAGE) in the Messages group. The footer says what it does: "Shows the Messages tab, delivers incoming messages and adds Send Message to the Contacts and Call Log menus." See Settings.

With the switch off:

  • the main window has three tabs (Dialpad, Contacts, Call Log) and no Messages tab;
  • there is no Send Message item, no notification, no Dock badge for messages and no message sound;
  • an incoming message is dropped and is not stored.

Switching it off does not delete anything: the conversations stay on the Mac and come back at once when you switch it on again.

The Messages tab

The fourth tab of the main window lists your conversations, the newest activity first. A conversation is one other party on one account, so the same number reached through two accounts is two conversations; the account name is shown next to the name.

Each row shows the name (a contact, otherwise the name sent with the message, otherwise the number), the account, the start of the last message ("You: …" when it is yours), the time and a blue count of unread messages. A red count on the tab adds up the unread messages of all conversations; it falls as you read them.

Action How
Open a conversation Click it, or select it and press Return.
Back to the list The back arrow, or Escape. A draft you typed stays.
Call the other party The green handset in the conversation header, or Call in the row's menu.
Add a number to Contacts Add to Contacts in the row's menu (only for a number that is not a contact yet).
Copy the number Copy Number in the row's menu.
Delete a conversation Delete Conversation… in the row's menu, or ⌘⌫; MacroSIP asks first. The messages are removed from this Mac only.
Copy or delete one message Right-click the bubble: Copy Text, Delete Message. Deleting needs no confirmation.

In a conversation your messages are on the right in the accent colour and the other party's on the left in grey. Return sends, Shift-Return or Option-Return starts a new line. A conversation counts as read while it is open in the main window and that window is in front.

With no messages yet the tab says "No messages" and "Messages you receive appear here. Click New Message to write one."

Writing a new message

Click New Message at the top of the list (it is unavailable while no account is switched on).

  1. Type the number, a SIP user such as 102, a sip: or tel: address or a name in To:. Suggestions from your contacts and directories appear as for the number field (Directory); pick one with the mouse or the arrow keys and Return. If the number field already held a number, it is copied into To.
  2. Check the line under it: "From …, the account chosen above". The message goes through the account chosen in the account row of the main window; change it there.
  3. Write the text and press Return or the round send button.

If a conversation with that number on that account already exists, MacroSIP opens it and keeps what you typed.

Statuses

Under each outgoing message you see what happened to it.

Shown Meaning
Sending… Waiting for the answer.
Sent The SIP server or the other party accepted the message. This is shown under your last message in the conversation. It is not a confirmation that the message reached a phone: "Accepted by the server. This does not confirm that the message reached the recipient's phone." There are no "Delivered" ticks.
Not sent · reason The message was not accepted. The reason is the answer of the server as it came ("404 Not Found", "408 Request Timeout", "480 Temporarily Unavailable") or "No connection" for a local problem, or "Interrupted" when MacroSIP was closed while the message was still being sent. A red mark appears beside the bubble and in the list row.

Press Retry next to the reason (or in the bubble's menu) to send the same text again through the same account; it goes to the end of the conversation with the current time.

If the account is switched off or was removed, you can still read the conversation, but the text field is unavailable ("… is switched off", "The account of this conversation was removed") and incoming messages for a switched-off account are not received.

Notifications, Dock badge and sound

  • Notification. Each incoming message posts a macOS notification with the sender as the title, the account name below it and the text. Clicking it brings MacroSIP forward and opens the conversation. Notifications are grouped by conversation and removed when you read or delete it. None is posted while that conversation is open in the front main window or while Do Not Disturb is on in MacroSIP (Incoming calls); macOS Focus modes work on their own. There is no notification sound.
  • Dock badge. The Dock icon shows one red number: unread messages plus unseen missed calls (Menu bar). The menu bar icon counts missed calls only.
  • Sound. Turn on New message in Settings › Audio › Sound events (off by default; the row exists only while messages are on) to hear two short high beeps on the speaker when a message arrives. Not while Do Not Disturb is on, and at most once every 2 seconds. See Audio.

With Do Not Disturb on, messages are still stored and counted, only without a notification or sound.

Send Message from Contacts and Call Log

With messages on, the context menu of a contact in Contacts and of an entry in Call Log has Send Message. It opens the Messages tab: the existing conversation with that number if there is one, otherwise a new message with the contact in the To field. From the Call Log the entry's own account is used. See Contacts and call log.

Limits

  • A message can be up to 2800 bytes of UTF-8 text. Cyrillic and most non-Latin letters take two bytes each, so that is roughly 1400 such characters. Beyond the limit the field shows "Too long to send" and the send button is disabled.
  • Not supported: group chat, attachments and pictures, typing indicators, end-to-end encryption and joining of long SMS parts (a long SMS may arrive as several separate messages). Links in messages are not clickable.

If a message shows Sent but the phone did not receive it, see Troubleshooting. Settings are listed in Settings.
