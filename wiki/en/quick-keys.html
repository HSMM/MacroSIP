Quick keys

Quick keys are up to twelve speed-dial buttons next to or under the main window, each with an optional BLF (busy lamp field) dot that shows whether that line is free, on the phone or ringing. The panel is off by default.

The panel

Settings › Quick keys › Show panel: Off, Right or Bottom.

Position Appearance
Right A 220 pt column to the right of the main window; the window widens from 340 to 560 pt. Header "Quick keys" with a gear button, then twelve rows: BLF dot, name, number and a type glyph. Empty slots read "Add key…".
Bottom A strip under the status bar; the window grows by about 110 pt. Three columns, two rows visible, the rest scrolls. Each cell shows the dot and the name; the tooltip gives number, state, type and shortcut.

The gear and an empty slot open Settings › Quick keys. Right-click a key for Edit… and Remove (clears the slot, no confirmation). The View menu offers Show Quick Keys / Hide Quick Keys, and the Call menu lists the keys under Quick keys with their shortcuts. All keys are disabled while no account is enabled.

Key types

A key has a name, a number and a type. What it does depends on whether you are in a call:

Type Idle In a call
Call Dials the number from the default outgoing account. Holds the current call and starts a new one.
DTMF Dials the digits as a number (so a key "Pickup *8" works). Sends the digits as DTMF on the active call.
Blind transfer Dimmed. Transfers the active call to the number at once.
Attended transfer Dimmed. Holds the active call and calls the number; Complete Transfer appears in the call panel.
Add to conference Dimmed. Calls the number and joins it to the active call when answered.
Call / Blind transfer Acts as Call. Acts as Blind transfer.
Call / Attended transfer Acts as Call. Acts as Attended transfer.
Call / Conference Acts as Call. Acts as Add to conference.

The three smart variants ("Smart: call when idle, act on the call when in one") are the usual choice for a colleague's extension: one key calls Natallia Karpovich when you are free and transfers the current caller to her when you are not.

BLF dots

Tick BLF on a key to watch the line state of its number. The dot uses the same presence subscription as a contact with Watch presence; a key and a contact with the same number share one subscription.

Dot Tooltip Meaning
green Available The line is registered and idle.
red On the phone The line is busy.
orange, blinking Ringing A call is ringing on that line; the key is tinted orange and shows "ringing" after the number.
grey No information No subscription answer (no presence on the PBX, the network is down, or the account is reconnecting). The key still works.

Ringing is shown only when the PBX reports call state in its presence or dialog notifications; otherwise a BLF key shows green and red only. A key with BLF off has no dot.

Pickup on a ringing key

Clicking a key that shows "ringing" dials the Pickup code from Settings › Quick keys followed by the key's number: with the default *8 and the number 101 it dials *8101, which on most PBXes answers that line's call on your phone. A key with an empty number dials the code alone (group pickup). Ask your PBX administrator for the right code if *8 does nothing.

Keyboard shortcuts

Key Action
⌘1 – ⌘9 Presses keys 1 to 9 in list order. Works while MacroSIP is the frontmost app, also when the panel is hidden. Does nothing for an empty or dimmed key.
Tab, Space Move between keys and press the focused key (panel only).

Keys 10 to 12 have no shortcut and are clicked only. Shortcuts follow the order of the list, so reordering rows reassigns them.

Configuring in Settings › Quick keys

The pane has a table of twelve fixed rows with the columns Name, Number, Type, BLF and Key, a count "5 of 12 keys", and two groups below.

  • "Drag rows to reorder. Name and Number are edited in place; double-click a row or start typing. The BLF box watches the number's line state."
  • Type is a popup with the eight types above; it is disabled on an empty row. BLF is disabled while the number is empty. Key shows ⌘1–⌘9 for rows 1–9 and "—" for the rest.
  • Panel group: Show panel (Off / Right / Bottom), with "Right widens the window to 560 pt; Bottom adds a 3-column strip."
  • Pickup code: default *8, "Used when you click a ringing key."

Example layout for a small office:

Name Number Type BLF
Maryna Sakalouskaya 101 Call / Attended transfer on
Yauheni Marozau 102 Call / Blind transfer on
Sales queue 600 Blind transfer off
Conference room 700 Add to conference off
Pickup *8 DTMF off

The keys are stored with the other settings in ~/Library/Application Support/MacroSIP/. Global hotkeys that work while another app is frontmost are planned for a later release.
