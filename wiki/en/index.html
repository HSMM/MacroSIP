MacroSIP

MacroSIP is a SIP softphone for macOS 14 and newer. It registers several SIP accounts at the same time, handles up to four calls with hold, transfer, local conference and recording, and fits into one small window plus a menu bar icon. The interface is native Swift and SwiftUI, and the SIP engine is PJSIP 2.17; there is no Electron and no Qt.

Versions

Versions read YY.MINOR.PATCH, so the line of 2026 is 26. The current release is 26.3.0 (5 November 2026); it adds text messages over SIP MESSAGE and makes the ringtone chosen in Settings › Audio really ring. The releases so far:

  • 26.3.0 (5 November 2026): Messages (off until switched on in Settings › General), the chosen ringtone is used.
  • 26.2.0 (4 November 2026): servers at a private address do not use STUN, stereo recordings keep both channels aligned, updates are also checked at launch.
  • 26.1.1 (4 November 2026): an account behind NAT registers again when the server leaves out its Contact, so incoming calls keep arriving.
  • 26.1.0 (3 November 2026): global hotkeys, import from MicroSIP, debug mode with a diagnostics archive.
  • 26.0.1 (14 October 2026): the interface in English and Russian only.
  • 26.0.0 (14 October 2026): the first public release.

Later releases bring notarization and video. The full plan is in docs/ROADMAP.md.

User guide

  • Installation — requirements, Homebrew or DMG, the first launch, updates, the log file.
  • Accounts — adding a SIP account, the Advanced group, several accounts, importing from MicroSIP, the account pop-up, status bar states.
  • Calls — dialing, the call panel, hold, mute, DTMF, transfers, several calls, conference, volumes, quality, recording, global hotkeys.
  • Incoming calls — the floating window and notification, auto-answer, Do Not Disturb, deny rules, the voicemail indicator.
  • Contacts and call log — the contact card, favourites, presence, call log entries and playback.
  • Messages — text messages over SIP, SMS from Asterisk, statuses, notifications, limits.
  • Asterisk-and-FreePBX-SMS — the PBX side of SMS: dialplan and endpoint settings.
  • Directory — LDAP, URL (CSV or JSON), Google Contacts and macOS Contacts sources, search and import.
  • Quick keys — speed-dial and BLF keys, pickup, ⌘1–⌘9.
  • Audio — devices, headset buttons, ringtone, hold music, sound events, audio test, echo cancellation, codecs, network settings that affect audio.
  • Settings — every pane and every row, in order.
  • Menu bar — the status item, its menu, the Dock badge for missed calls and messages.
  • Troubleshooting — first launch, microphone, 403 and 401, TLS, one-way audio, logs, debug mode and the diagnostics archive, where data is stored, how to report an issue.
