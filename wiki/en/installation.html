Installation

Requirements

  • macOS 14 (Sonoma) or newer.
  • A Mac with Apple Silicon or Intel. The app and the DMG are universal, so one download runs natively on both.
  • A SIP account: the server address, username and password from your phone provider or PBX administrator. Contacts and the call log work without an account.

Both the Homebrew cask and the DMG are available from the 26.0.0 release; building from source is described in Building.

With Homebrew

brew tap hsmm/tap
brew install --cask hsmm/tap/macrosip

The cask installs the same signed DMG that GitHub Releases offers. The cask is marked auto_updates, so brew upgrade leaves an app alone that updates itself.

From the DMG

  1. Download MacroSIP-<version>.dmg from the latest release.
  2. Open the DMG and drag MacroSIP onto the Applications folder.
  3. Open the app once as described below.

First launch: the Gatekeeper step

MacroSIP is signed ad hoc, not notarized with an Apple Developer ID, so macOS refuses to open it the first time ("cannot be opened because the developer cannot be verified"). Either of these works once:

  • Right-click (or Control-click) MacroSIP in Applications, choose Open, then confirm in the dialog.

  • Or remove the quarantine flag in Terminal:

    xattr -dr com.apple.quarantine /Applications/MacroSIP.app

After that the app opens normally. Developer ID signing and notarization are planned for a later release, when a signing identity is available.

First window

With no accounts the main window shows "Add a SIP account to start calling" and an Add Account… button. The account editor is described in Accounts. The menu bar icon appears from the first launch, in the offline state.

Microphone permission

MacroSIP asks for the microphone on the first call, not at launch. Choose Allow. If you decline, the call panel shows "Microphone access is off" with an Open System Settings button; allow MacroSIP under Privacy & Security › Microphone.

Updates

The app updates itself.

What Where Behaviour
Automatic check automatic MacroSIP checks at launch and then once a day, and asks before installing.
Check right away MacroSIP menu › Check for Updates…, or Settings › General › Updates › Check Now The last check date is shown as "Last checked …" or "Not checked yet".
Turn the automatic check off Settings › General › Updates › Check for updates automatically "At launch and once a day. MacroSIP asks before installing an update."
Release candidates Settings › General › Updates › Include release candidates "Test builds of the next version, offered before it is final." On by default when the running build is itself a release candidate, otherwise off.

Updates are signed (EdDSA) and verified before they are installed, and the updated app opens without the first-launch dialog. An update found during a call waits until the last call ends; "Install and Relaunch" during a call waits too. Quitting with a call in progress asks "End the call and quit?".

Because the app is signed ad hoc, macOS ties the microphone permission to the exact build. After each update macOS asks for microphone access again; allow it once more on the first call. This stops once the app is signed with a Developer ID.

"Updates work only in the installed app": a build run from a build folder or started with a mock engine does not check for updates.

Launch at login

Settings › General › Launch at login registers MacroSIP as a login item. There is no prompt about this on first run. If macOS needs your approval, the row says "Allow MacroSIP in System Settings › General › Login Items." with an Open Login Items… button.

Where the log file is

MacroSIP writes ~/Library/Logs/MacroSIP/MacroSIP.log, 2 MB per file, 3 files kept. Settings › General has Open Log Folder (reveals the log in Finder) and Copy Diagnostics (versions, accounts and settings without passwords, ready to paste into a bug report). Both sit in the collapsed Advanced group at the bottom of the General pane, under the header "Troubleshooting". See Troubleshooting for how to use them.

Uninstalling

Drag MacroSIP out of Applications (or brew uninstall --cask macrosip). Your data stays in ~/Library/Application Support/MacroSIP/ (accounts, contacts, call log, settings as JSON) and in the login Keychain (passwords, service com.hsmm.macrosip); recordings stay in ~/Music/MacroSIP Recordings unless you chose another folder. Delete those by hand if you want a clean removal.
